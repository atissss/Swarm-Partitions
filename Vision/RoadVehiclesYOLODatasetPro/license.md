## Overview

This dataset is a merger and modification of four original collections:
1. [Aerial Traffic Images](https://www.kaggle.com/datasets/cihangiryiit/aerial-traffic-images)  
2. [VisDrone Dataset](https://www.kaggle.com/datasets/kushagrapandya/visdrone-dataset)  
3. [Roundabout Aerial Images for Vehicle Detection](https://www.kaggle.com/datasets/javiersanchezsoriano/roundabout-aerial-images-for-vehicle-detection)  
4. [VSAI_Dataset](https://www.kaggle.com/datasets/dronevision/vsaiv1)  

Each source dataset is governed by its own license terms as outlined below.
